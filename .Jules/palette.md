## 2024-05-18 - Added aria-hidden to decorative Markdown icons\n**Learning:** In GitBook environments using raw HTML for FontAwesome icons inside Markdown, textual fallbacks (like ':envelope:') can be read redundantly by screen readers if the icons are purely decorative. \n**Action:** Always add aria-hidden="true" to purely decorative <i> tags embedded in Markdown files to improve screen reader experience.
