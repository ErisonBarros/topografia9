## 2024-07-22 - Hide decorative GitBook icon syntax from screen readers
**Learning:** In this GitBook project, FontAwesome icons are embedded directly as HTML `<i>` tags alongside textual fallbacks in the format `:icon-name:` (e.g., `<i class="fa-envelope">:envelope:</i>`). If these tags are not hidden using `aria-hidden="true"`, screen readers will pronounce the fallback text (like "colon envelope colon"), creating a redundant and poor experience for screen reader users. Additionally, ensuring the main `lang` configuration (e.g., `lang: pt-BR` in `_config.yml`) is correct guarantees that text is pronounced using the correct language synthesizer.
**Action:** Always add `aria-hidden="true"` to decorative HTML `<i>` tags in Markdown that contain textual fallbacks to prevent screen readers from reading them out loud.
