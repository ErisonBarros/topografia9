## 2026-07-15 - Added aria-hidden to decorative FontAwesome tags
**Learning:** In GitBook, raw HTML decorative FontAwesome tags embedded in Markdown should include the aria-hidden="true" attribute to prevent screen readers from reading textual fallbacks that are unhelpful context to visually impaired users.
**Action:** Add aria-hidden="true" to FontAwesome <i> tags to improve screen reader experience on decorative icons.
