## 2026-06-09 - Add aria-hidden to decorative GitBook <i> tags
**Learning:** Decorative FontAwesome <i> tags embedded in GitBook markdown need aria-hidden="true" to prevent screen readers from reading textual fallbacks (e.g. :map-marked-alt:).
**Action:** Add aria-hidden="true" to decorative <i> tags when finding them in GitBook markdown.
