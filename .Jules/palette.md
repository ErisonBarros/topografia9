## 2024-07-15 - Add lang attribute to Jekyll site
**Learning:** For Jekyll-based GitHub Pages sites, adding `lang: pt-BR` to the `_config.yml` provides a crucial micro-accessibility improvement. It ensures that screen readers recognize the language of the content and pronounce it correctly with the proper accent and rules, which is especially important for sites not in English.
**Action:** Created `_config.yml` with `lang: pt-BR` to improve the accessibility of the site.
