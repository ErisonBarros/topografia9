## 📅 tópicos cubiertos

A disciplina aborda os seguintes blocos temáticos:

1. **Equipamentos e instalação** — teodolito, nível, estação total, GNSS
2. **Taqueometria** — medições angulares e lineares
3. **Cálculo de poligonais** — cálculo de coordenadas
4. **Sistemas de referência** — SIRGAS2000, UTM, datum
5. **Escalas e precisão** — aplicações práticas
6. **Locação de obras** — técnicas com gabaritos

Para o conteúdo detalhado, ver [`conteudo.md`](./conteudo.md).
