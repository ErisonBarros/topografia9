# Agent_Claude_UFPE

Central de pendências, tarefas e planejamento semanal das atividades na UFPE.

- `pendencias.md`: lista mestra separada por prioridade (urgente, importante, pode esperar)
- `semanas/`: um plano por semana (`AAAA-MM-DD.md`, data da segunda-feira), com próximos passos por dia
- `notas/`: notas soltas de reuniões, avisos e ideias
